BM25 run with and without the negation tokens

To check what the negation token in keyword search actually does, we ran it again with all negation tokens removed. In three of four model and language combinations the results did not change at all. The reason is in the questions: only 2 of 24 negation questions contain a negation word. People ask "may the employer...", and the answer is a prohibition. So the token has nothing to match. Where keyword search did help, for e5-base on Kazakh, the help came from reducing words to their base forms, not from negation.
