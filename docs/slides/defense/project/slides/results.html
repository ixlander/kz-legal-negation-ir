Here is the main table for bge-m3 on the test split, our baselines and our components on the same questions. Dense search alone is already strong. Our hybrid with the morphological BM25 lowers recall slightly, and our NLI reranker is never better than the off-the-shelf cross-encoder, which is the best row almost everywhere. With the weaker e5-base model the hybrid does help on Kazakh, from 0.47 to 0.68 on negation questions. But none of the forty planned comparisons survives the multiple-testing correction, so we present these as pilot results, not as proven differences.
