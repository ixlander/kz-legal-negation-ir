Exact two-sided sign test on changed questions · results/stats_extra.json

This slide is about how much our numbers can carry. The bootstrap intervals flagged five differences, but each of them comes from four or five questions that all changed in the same direction. An exact sign test on such a small count can never go below about 0.06, and after correcting for the forty comparisons we planned, none of them is significant. So we present the retrieval results as a pilot: they show which way things point, not proven effects. The fix is more questions, which we did not have time to annotate.
