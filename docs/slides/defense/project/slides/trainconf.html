The training setup. AdamW with a low learning rate of ten to the minus five, because the start model already does NLI and we only want to adapt it; linear warm-up over six percent of steps, then linear decay. Effective batch thirty-two through gradient accumulation, which is what fits in six gigabytes. Two epochs; after each we measure macro F1 on one half of the Kazakh NLI test and keep the best epoch, and we report on the other half, so the reported numbers never influenced selection. Classes are balanced, so we report macro F1 and accuracy. We trained four data variants to test two hypotheses.
