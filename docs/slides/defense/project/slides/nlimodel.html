3 · The trained model

The NLI reranker reads paragraph and question together and outputs three probabilities

[CLS] paragraph (premise) [SEP] question (hypothesis) [SEP]

↓ token ids + attention mask, ≤128 tokens in training

mDeBERTa-v3-base · 12 layers · 768 hidden · 12 heads · disentangled attention

↓ [CLS] pooler (dense + GELU) → linear 768 × 3

softmax → P(entailment), P(neutral), P(contradiction)

Pretrained

MoritzLaurer mDeBERTa-v3 xnli-2mil7 (2.7M NLI pairs, incl. machine-translated ru and tr)

Trainable

All 278.8M parameters (192.8M in embeddings), nothing frozen

Loss

3-class cross-entropy

Rerank score

S1 = P(e) − P(c); final = norm. B2 score + 0.25 · S1 (chosen on dev)

Earlier attempt: XLM-R-base trained from scratch on the same data was worse everywhere (Kardeş 0.71 vs 0.79)

This is the model we trained. It is a cross-encoder: the paragraph and the question go in as one sequence, so attention can relate a negation in the paragraph to the question. The encoder is mDeBERTa-v3-base, twelve layers. The classification head takes the first token, passes it through a dense layer with GELU and a linear layer to three classes, and a softmax gives entailment, neutral and contradiction. We start from a checkpoint already trained on NLI, fine-tune all weights with cross-entropy, and use entailment minus contradiction as the reranking score, mixed with the retrieval score.
