BM25 run with and without the negation tokens · IDF of «не» 0.80

To check what the negation token in keyword search actually does, we ran it again with all negation tokens removed. In three of four model and language combinations the results did not change. Two reasons. First, the token is everywhere: almost half of all paragraphs contain «не», so keyword search gives it almost no weight and it cannot tell "taxable" from "not taxable". Second, the questions rarely contain negation: people ask "may the employer..." and the answer is a prohibition. Where keyword search did help, for e5-base on Kazakh, the help came from reducing words to their base forms.
