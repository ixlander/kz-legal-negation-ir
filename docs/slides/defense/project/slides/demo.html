Now the live demo. We type a question, ideally one you give us, in Russian or Kazakh. The page shows the preprocessing first: the subword tokens and ids the model sees, and the BM25 tokens with the negation token. Then the top five of dense search, of the hybrid, and after reranking, each with its score and the polarity the rule assigns. For the final five it shows the NLI model’s three probabilities. If the question comes from our test split, the gold and twin are marked, so you can see where each system put them. The demo calls the same functions as the evaluation scripts.
