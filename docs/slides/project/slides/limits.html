Be honest about the limits. With about twenty test questions per group, only large differences can be detected, and none of our comparisons survives an exact test. All negation questions are yes or no questions, and many Russian tax questions use abbreviations that the law does not. One teammate checked everything after seeing the drafts. Next we would build 150 or more balanced questions and freeze the method before looking at them, add a second annotator working blind, judge every system's top results, and write question pairs that ask the same thing with opposite polarity. We drafted 69 balanced questions but had no time to annotate them, so they are not in any number shown.
