4 · Learning curves

Validation loss is lowest at the end of epoch 1, then rises: the second epoch overfits

Epoch 1: val loss 0.61 → 0.47, macro F1 0.803 → 0.820 (kept)

Epoch 2: train loss ≈ 0.40, val loss → 0.53, F1 0.811

Validation = Kardeş kk selection half · results/nli_curves_a-curves.json · repeat of variant a, same config

These are the learning curves, logged every fifty steps for training and every two hundred for validation. In the first epoch both losses fall and validation macro F1 rises from 0.803 to about 0.82. In the second epoch the training loss keeps falling, to about 0.40, while validation loss climbs back to 0.53 and F1 drops: classic overfitting. Our selection rule keeps the best epoch, epoch one, with 0.8195; the original training run selected the same epoch with the same score. This is also why we did not train longer: the start model already knows NLI, so two epochs are enough.
