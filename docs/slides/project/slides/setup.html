Before trusting our own numbers, we ran the same code on public benchmarks. On NevIR, the English negation benchmark, our reranker scores 0.651 where the published number is 0.652. On RuLawRetrieval, a Russian labor-law benchmark, our numbers land in the published range; note that the published column comes from the dataset card and uses other model sizes, so it is for comparison only. For Kazakh there is no published number on our subsample of KazQAD, so we only show that our Kazakh analyzer improves keyword search from 0.348 to 0.465.
