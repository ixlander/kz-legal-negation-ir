Be honest about the limits. With about twenty test questions per group, only large differences, around 0.2, can be detected. All our negation questions are yes or no questions and all general ones are what or how questions, so part of the gap we measure is just question type. One teammate checked everything, after seeing the drafts, and each question has one marked answer. Each NLI variant was trained once. Next we would add 150 or more balanced questions, a second annotator working blind, judgments for every system's top results, and handling of abbreviations. We already drafted 69 such questions but had no time to annotate them, so they are not in any number shown.
