5 · Metrics and protocol

Every metric is computed on the held-out test split; dev only chose α, scoring and fusion

Metric

Definition

Recall@5

share of a question’s gold paragraphs in the top 5, averaged over questions (full 22-code corpus)

Negation Gap

Recall@5(general) − Recall@5(negation), same language and system

Twin-above-Gold

share of negation questions with a twin where the best twin ranks above the best gold (lower is better)

NLI accuracy, macro F1

3 classes, unweighted mean of per-class F1; classes are balanced

Statistics

paired bootstrap (1,000 resamples, 95% CI), exact sign test, Holm over 40 pre-registered comparisons

Not measured: answer correctness; other relevant paragraphs (one gold per question) · src/eval/metrics.py

All retrieval metrics are computed on the test split over the full corpus. Recall at five fits the use case, because an assistant reads the top few paragraphs. Negation Gap compares the two kinds of questions, and Twin-above-Gold counts exactly the error we care about. For NLI we report accuracy and macro F1, since the classes are balanced. What these metrics do not measure: whether an answer would be correct, and other relevant paragraphs, since only one gold is annotated. With about twenty questions per cell, one question moves Recall at five by 0.05, so we test every difference with bootstrap intervals and an exact sign test.
