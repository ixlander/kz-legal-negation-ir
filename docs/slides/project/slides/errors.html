20 test questions with the most Recall@5 misses, read one by one

We took the twenty test questions that the systems missed most often and read the results by hand. The largest group, seven, is simply a weak model on Kazakh: e5-base fails where bge-m3 succeeds. Only four are the polarity errors this project is about, where the opposite rule ranks above the correct one; in one of those four, the opposite rule, that fines are deductible, had not been marked as a twin by us. The rest are ordinary search problems: neighbouring articles, abbreviations, an answer hidden inside a long list, and one question with a second correct answer we did not mark.
