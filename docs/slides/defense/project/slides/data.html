The corpus is official legislation: every code whose Russian and Kazakh versions have the same revision. Questions are drafted with an LLM and checked, with gold and twin ids, by Balym, a native speaker of Kazakh. Five pairs per slice are a dev split for tuning; thirty-nine pairs are the test split we report. For the NLI model, the training data is XNLI Russian and Turkish plus pairs we generated by rules. To avoid leakage the generator only uses the twenty distractor codes, never Labor or Tax, and its own test set is held out by article. Checkpoints are chosen on one half of the Kazakh NLI test and reported on the other half.
