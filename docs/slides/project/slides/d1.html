D1 checks the embedding models before any search. We take a legal sentence and measure how close it is to an alternative and to its negation. Against a full paraphrase, every model puts the negation closer, which looks like a failure. But a paraphrase changes about 20 words and a negation changes one, so that comparison is unfair. The fair test is the right column: an alternative that also changes one word, a synonym. There the margin is positive for all six models in Russian and five in Kazakh. So the models do notice negation, only weakly: the gap is a few hundredths of cosine similarity.
